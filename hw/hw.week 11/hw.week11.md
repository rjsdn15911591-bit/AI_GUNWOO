## 실습 1: 슈뢰딩거 방정식 수치 풀기 (`01schrodinger.py`)

### 수치 해법 구현

슈뢰딩거 방정식 `Hψ = Eψ`를 유한 차분법으로 풀기 위해 해밀토니안 행렬을 다음과 같이 구성했다:

```
H = T + V
T_ij = ℏ²/(2m·dx²) × { 2   (i=j)
                        {-1  (|i-j|=1)
                        { 0  (otherwise)
```

`scipy.linalg.eigh`를 사용해 고유값(에너지)과 고유벡터(파동함수)를 계산하였고, 각 파동함수는 `∫|ψ|²dx = 1` 조건으로 정규화하였다.

---

### 1-1. 무한 사각 우물 (Infinite Square Well)

**이론값과 수치값 비교:**

| 양자수 n | 이론 에너지 Eₙ = n²π²ℏ²/(2mL²) | 수치 계산값 |
|---------|-------------------------------|-----------|
| 1 | 0.0493 (≈π²/200) | 0.049 |
| 2 | 0.1974 | 0.197 |
| 3 | 0.4435 | 0.443 |
| 4 | 0.7890 | 0.789 |
| 5 | 1.2337 | 1.233 |

**분석:**
- 수치값이 이론값과 매우 잘 일치함을 확인하였다.
- n이 증가할수록 에너지는 n²에 비례하여 증가한다.
- n=1 상태(바닥 상태)에서도 에너지가 0이 아닌 **영점 에너지(zero-point energy)**가 존재한다. 이는 불확정성 원리의 직접적인 결과이다 — 입자를 유한한 공간에 가두면 운동량의 불확정성이 생기고, 이로 인해 최소 에너지가 0보다 크다.
- 파동함수의 노드(node) 수: n번째 상태는 (n-1)개의 노드를 가진다.

**핵심 관찰:**  
n=1 파동함수는 상자 중앙에서 확률 밀도가 최대이고, n=2는 중앙이 노드(확률=0)이다. 이는 완전히 고전 물리학에 반하는 결과이다.

---

### 1-2. 조화 진동자 (Harmonic Oscillator)

**이론값과 수치값 비교 (ω=1):**

| 양자수 n | 이론 에너지 Eₙ = ℏω(n+½) | 에너지 간격 |
|---------|------------------------|-----------|
| 0 | 0.5 | - |
| 1 | 1.5 | ℏω = 1.0 |
| 2 | 2.5 | ℏω = 1.0 |
| 3 | 3.5 | ℏω = 1.0 |
| 4 | 4.5 | ℏω = 1.0 |

**분석:**
- 에너지 준위가 **등간격(equally spaced)**으로 양자화된다는 점이 가장 큰 특징이다.
- 무한 우물과 달리 에너지 간격이 n에 무관하게 일정하다.
- 파동함수는 가우시안 봉투(Gaussian envelope) 안에 에르미트 다항식(Hermite polynomial) 패턴을 가진다.
- **고전적 전환점** 밖으로 파동함수가 침투하는 것이 관찰된다 — 이것이 양자 터널링의 기초이다.

---

### 1-3. 유한 사각 우물 (Finite Square Well)

**무한 우물과의 차이:**

| 특성 | 무한 우물 | 유한 우물 |
|-----|---------|---------|
| 경계 조건 | ψ(0) = ψ(L) = 0 (엄격) | 벽 밖으로 지수 감소 허용 |
| 파동함수 | 경계에서 정확히 0 | 경계에서 연속적이나 0이 아님 |
| 에너지 준위 | 무한히 많음 | 유한개 (V₀에 의존) |
| 속박 상태 | 모두 속박 | 유한개만 속박 |

**분석:**
- 파동함수의 "꼬리(evanescent tail)"가 금지 영역으로 침투하는 현상을 확인하였다.
- 에너지가 낮을수록 꼬리가 짧고, 에너지가 높을수록 꼬리가 길다.
- 이 침투가 바로 양자 터널링의 직접적인 원인이다.

## 실습 2: 파동함수 시각화 (`02wavefunction.py`)

### 2-1. 가우시안 파동 패킷 (Gaussian Wave Packet)

**초기 상태 설정:**
- 중심 위치: x₀ = 0.0
- 너비: σ = 2.0
- 평균 운동량: k₀ = 2.0

**불확정성 원리 확인:**

```
Δx ≈ σ = 2.0
Δp ≈ ℏ/(2σ) = 1/(2×2) = 0.25
Δx·Δp = 0.5 = ℏ/2  ← 최소 불확정성 상태!
```

가우시안 파동 패킷은 **최소 불확정성 상태(minimum uncertainty state)**임을 수치 계산으로 확인하였다.

**파동함수의 구성 요소:**
- 실수부(파란색): 진동하는 파동
- 허수부(주황색): 실수부에서 π/2 위상 이동
- 확률 밀도(녹색): |ψ|² — 항상 양수이며 가우시안 분포

**관찰:** 운동량 k₀ = 2.0이 있으므로 파동의 위상이 +x 방향으로 진행한다. 확률 밀도의 중심은 고전 입자처럼 이동하지만 시간이 지날수록 분산된다.

---

### 2-2. 중첩 상태 (Superposition States)

무한 우물의 에너지 고유상태를 중첩하여 다음 세 경우를 시각화하였다:

1. **n=1 + n=3 중첩:** `ψ = (ψ₁ + ψ₃)/√2`
   - 두 상태의 간섭으로 비대칭 확률 분포 형성
   - 왼쪽과 오른쪽의 확률이 시간에 따라 진동 (주파수: ΔE/ℏ)

2. **n=1 + n=5 중첩:** 더 복잡한 간섭 패턴, 더 빠른 진동

3. **동등 중첩 (n=1,2,3,4,5):** 모든 상태가 동등하게 기여
   - 확률이 여러 곳에 분산
   - 양자 컴퓨터 큐비트의 동작 원리와 동일

**양자 중첩의 의의:**
- 측정 전에는 여러 에너지 상태가 동시에 존재
- 측정하는 순간 하나의 에너지 값으로 "붕괴(collapse)"
- 이것이 슈뢰딩거의 고양이 역설의 핵심

---

### 2-3. 수소 원자 오비탈 (Hydrogen Atom Orbitals)

1D 근사로 수소 원자의 방사형(radial) 파동함수를 시각화하였다:

| 오비탈 | 양자수 (n, l) | 노드 수 | 특징 |
|--------|-------------|--------|-----|
| 1s | (1, 0) | 0 | 중심에서 최대, 구형 대칭 |
| 2s | (2, 0) | 1 | 구형, 반지름 방향 노드 1개 |
| 2p | (2, 1) | 0 (방사형) | 아령 모양, 방향성 |
| 3s | (3, 0) | 2 | 구형, 반지름 방향 노드 2개 |

**에너지 준위:**
```
Eₙ = -13.6 eV / n²
E₁ = -13.6 eV (1s)
E₂ = -3.4 eV  (2s, 2p)
E₃ = -1.51 eV (3s, 3p, 3d)
```

같은 n에 해당하는 오비탈들이 같은 에너지를 가진다(縮退, degeneracy).

## 실습 3: 터널링 효과 (`03tunneling.py`)

### 3-1. 사각 장벽 터널링

**시뮬레이션 조건:**
- 장벽 높이: V₀ = 2.0
- 장벽 너비: a = 2.0
- 입자 에너지: E = 0.5, 1.0, 1.5 (모두 < V₀)

**투과 계수 계산:**

```
κ = √(2m(V₀-E)/ℏ²)
T ≈ exp(-2κa)
```

| 입자 에너지 E | κ | 이론 투과율 T |
|------------|---|-------------|
| 0.5 | √3 ≈ 1.73 | exp(-6.93) ≈ 0.00098 |
| 1.0 | √2 ≈ 1.41 | exp(-5.66) ≈ 0.00350 |
| 1.5 | 1.00 | exp(-4.00) ≈ 0.01832 |

**분석:**
- 에너지가 V₀ = 2.0에 가까워질수록 투과율이 급격히 증가한다.
- E = 0.5일 때 약 0.1%, E = 1.5일 때 약 1.8%로 18배 차이가 난다.
- 장벽 내부에서 파동함수가 지수적으로 감소하는 것을 시각적으로 확인하였다.

**파동함수 구조:**
- 왼쪽: 입사파 + 반사파의 간섭 (정상파 패턴)
- 장벽 내부: 지수 감쇠 (evanescent wave)
- 오른쪽: 순수 투과파 (진폭이 매우 작음)

---

### 3-2. 공명 터널링 (Resonant Tunneling)

**이중 장벽 구조 (Double Barrier):**
```
V(x): 장벽1 | 우물 | 장벽2
```

**관찰 결과:**
- 우물의 에너지 준위에 해당하는 특정 에너지에서 투과율이 **T = 1** (100%)에 도달한다!
- 이것이 공명 터널링(Resonant Tunneling)이다.
- 에너지가 공명 조건에서 조금만 벗어나도 투과율이 급격히 감소한다.

**응용 의의:**
공명 터널링 다이오드(RTD)는 이 원리를 이용한 초고속 스위칭 소자로, 피코초(ps) 단위의 스위칭 속도를 달성한다. 양자 캐스케이드 레이저(QCL)도 같은 원리를 이용한다.

---

### 3-3. 터널링 매개변수 의존성

세 변수의 영향을 독립적으로 분석하였다:

**1. 장벽 높이 V₀ 변화 (E=1.0, a=2.0 고정):**

| V₀ | κ | T (근사) |
|----|---|---------|
| 1.5 | 1.00 | ~0.018 |
| 2.0 | 1.41 | ~0.0035 |
| 3.0 | 2.00 | ~0.00034 |
| 5.0 | 2.83 | ~0.0000027 |

결론: V₀ 증가 시 투과율은 지수적으로 감소

**2. 장벽 너비 a 변화 (E=1.0, V₀=2.0 고정):**

| a | T (근사) |
|---|---------|
| 1.0 | ~0.059 |
| 2.0 | ~0.0035 |
| 3.0 | ~0.00021 |
| 4.0 | ~0.000012 |

결론: a 두 배 → T는 exp(-2κa) 법칙으로 지수 감소

**3. 입자 에너지 E 변화 (V₀=2.0, a=2.0 고정):**

에너지가 증가할수록 κ가 작아지므로 투과율이 단조 증가. E → V₀에서 급격히 증가하고 E > V₀이면 공명 현상이 나타난다.

**핵심 메시지:** 터널링은 `T ∝ exp(-2κa)`로 장벽 너비에 **지수적**으로 의존한다. 원자 간격(~Å 단위)의 변화가 터널링 전류를 수십 배 바꿀 수 있어 STM(주사 터널링 현미경)의 원리가 된다.

## 실습 4: 유한 우물과 조화 진동자 상세 분석 (`04wells_oscillator.py`)

### 4-1. 유한 우물의 깊이(V₀) 의존성

**분석 조건:** V₀ = 5.0, 10.0, 20.0

| V₀ | 속박 상태 수 | 바닥 상태 에너지 | 특징 |
|----|-----------|----------------|-----|
| 5.0 | 약 2개 | 비교적 높음 | 파동함수 꼬리 길다 |
| 10.0 | 약 3개 | 낮아짐 | 파동함수 꼬리 중간 |
| 20.0 | 약 5개 | 더욱 낮아짐 | 무한 우물에 근접 |

**결론:**
- V₀가 클수록 더 많은 속박 상태가 존재한다.
- V₀ → ∞ 극한에서 무한 사각 우물로 수렴한다.
- 각 에너지 준위가 낮아지는 이유: 깊은 우물이 입자를 더 강하게 속박하여 운동에너지가 감소하기 때문이다.

---

### 4-2. 유한 우물의 너비(L) 의존성

**분석 조건:** L = 2.0, 5.0, 10.0

| L | 바닥 상태 에너지 | 이유 |
|---|----------------|-----|
| 2.0 | 높음 | Δx 작음 → Δp 큼 → E 큼 |
| 5.0 | 중간 | - |
| 10.0 | 낮음 | Δx 큼 → Δp 작음 → E 작음 |

**불확정성 원리와의 연결:**
```
E_min ~ (Δp)²/2m ~ ℏ²/(2mL²)
```
우물이 좁아질수록 영점 에너지가 1/L²에 비례하여 증가한다. 이것이 나노 구조(양자점, 양자선)에서 크기를 줄이면 에너지 간격이 커지는 원인이다.

### 4-3. 조화 진동자 상세 분석

**수치 계산 결과 (ω=1.0):**

| n | Eₙ (수치) | Eₙ (이론) | 파동함수 특성 |
|---|---------|---------|-------------|
| 0 | 0.500 | 0.5 | 우함수, 노드 0 |
| 1 | 1.500 | 1.5 | 기함수, 노드 1 |
| 2 | 2.500 | 2.5 | 우함수, 노드 2 |
| 3 | 3.500 | 3.5 | 기함수, 노드 3 |
| 4 | 4.500 | 4.5 | 우함수, 노드 4 |

**에르미트 함수의 특성:**
- 짝수 n: 우함수(even function), 홀수 n: 기함수(odd function)
- V(x)가 x에 대해 대칭이므로 고유함수도 반드시 기함수 또는 우함수
- 고전적 전환점(turning point): Eₙ = ½mω²x² → x_tp = √(2Eₙ/mω²)

| 특성 | 무한 사각 우물 | 유한 사각 우물 | 조화 진동자 |
|-----|-------------|-------------|-----------|
| 포텐셜 모양 | 직사각형 | 유한 직사각형 | 포물선 |

| 속박 상태 수 | 무한 | 유한 | 무한 |

### 4-5. 고전 vs 양자 비교

**고전 조화 진동자:**
- 입자는 전환점 사이에서만 운동
- 전환점에서 속도 = 0, 시간을 가장 오래 보냄
- 따라서 확률 분포가 전환점 근처에서 높음

**양자 조화 진동자 (낮은 n):**
- n=0: 중앙에서 확률 최대 (고전과 정반대!)
- 전환점 밖으로도 침투 (터널링)

**양자-고전 대응 (Bohr Correspondence Principle):**
- n이 커질수록 양자 확률 분포가 고전 확률 분포에 수렴한다.
- n=20 이상에서는 양자 분포의 평균이 고전 분포와 거의 일치한다.

시뮬레이션에서 n=0~4와 n=10, n=20을 비교하면 이 대응 원리를 시각적으로 확인할 수 있다.

## 핵심 개념 정리

### Q1. 에너지가 왜 양자화되는가?

입자가 유한한 공간에 갇히면 경계 조건에 의해 파동함수의 형태가 제한된다. 파동함수는 경계에서 0이 되거나 연속성 조건을 만족해야 하므로, 오직 특정 파장(λₙ = 2L/n)만 허용된다. 드브로이 관계식 `p = h/λ`에 의해 운동량도 특정 값만 가능하고, 따라서 에너지 `E = p²/2m`도 불연속적이 된다.

수학적으로는 슈뢰딩거 방정식이 **경계값 문제(boundary value problem)**가 되어, 고유값(eigenvalue)이 이산적으로 존재하기 때문이다.

### Q2. 터널링이 왜 일어나는가?

고전 물리학에서는 입자의 총 에너지 E가 포텐셜 V보다 작으면 그 영역에 존재할 수 없다. 하지만 양자역학에서 파동함수는 슈뢰딩거 방정식을 따르므로, E < V인 영역에서도 방정식의 해가 존재한다. 이 영역에서 해는 `exp(-κx)` 형태의 지수 감쇠 함수이며, 이것이 0이 되지 않는 한 장벽 너머에도 확률 밀도가 존재한다.

직관적으로: 입자는 입자가 아니라 파동이므로, 빛이 유리를 통과하듯 장벽을 "스며들" 수 있다.

### Q3. 왜 영점 에너지(zero-point energy)가 존재하는가?

만약 입자가 완전히 정지해 있다면(E=0), 정확한 위치(상자 안)와 정확한 운동량(p=0)을 동시에 알 수 있다. 이는 하이젠베르크 불확정성 원리 `Δx·Δp ≥ ℏ/2`에 위배된다. 따라서 입자는 항상 어느 정도의 운동에너지를 가져야 하며, 이것이 영점 에너지이다.

수치 계산에서 무한 우물의 바닥 상태 에너지가 E₀ ≈ 0.049 > 0 임을 확인하였다.

### Q4. 불확정성 원리의 의미

```
Δx · Δp ≥ ℏ/2
```

이것은 측정 기술의 한계가 아니라 **자연의 근본 법칙**이다. 입자가 넓게 퍼진 파동 패킷이면(Δx 큼) 운동량이 잘 정의되고(Δp 작음), 반대로 좁은 파동 패킷이면(Δx 작음) 운동량이 불확정해진다(Δp 큼).

가우시안 파동 패킷 시뮬레이션에서 σ를 줄이면 파동 패킷의 주파수 스펙트럼이 넓어지는 것으로 이를 확인하였다.

### Q5. 고전-양자 대응 원리 (Bohr's Correspondence Principle)

양자역학의 결과는 n → ∞ (또는 ℏ → 0) 극한에서 고전 역학으로 수렴한다. 조화 진동자에서 n=20 이상의 파동함수 확률 분포를 보면, 양자 분포의 포락선(envelope)이 고전 확률 분포와 일치함을 확인하였다. 이것이 거시 세계에서 양자 효과가 관찰되지 않는 이유이다.

## 학습 체크리스트

### 기본 개념
- [x] 슈뢰딩거 방정식의 의미를 이해했는가?  
  → 입자의 파동함수가 만족해야 하는 파동 방정식. 고유값 E와 고유벡터 ψ가 각각 에너지와 파동함수를 나타냄.
- [x] 파동함수 ψ와 확률 밀도 |ψ|²의 차이를 아는가?  
  → ψ는 복소수 함수이고 직접 관측 불가. |ψ|²가 입자를 해당 위치에서 발견할 확률 밀도.
- [x] 양자화(Quantization)가 무엇인지 설명할 수 있는가?  
  → 경계 조건으로 인해 에너지가 불연속적인 값만 가질 수 있는 현상.
- [x] 불확정성 원리를 자신의 말로 설명할 수 있는가?  
  → 위치와 운동량을 동시에 임의의 정밀도로 알 수 없다는 자연의 근본 법칙.

### 응용 개념
- [x] 터널링 효과를 이해하고 예시를 들 수 있는가?  
  → 에너지가 장벽보다 낮은 입자가 장벽을 통과하는 현상. 예: 알파 붕괴, STM, Flash 메모리.
- [x] 무한 우물과 유한 우물의 차이를 아는가?  
  → 무한 우물은 경계에서 ψ=0, 유한 우물은 경계 밖으로 지수 감쇠하며 침투.
- [x] 조화 진동자의 특징 (등간격 에너지)을 아는가?  
  → Eₙ = ℏω(n+½), 모든 준위 사이 에너지 차이가 ℏω로 일정.
- [x] 고전-양자 대응 원리를 이해하는가?  
  → n이 크면 양자 결과가 고전 결과에 수렴. 거시 세계에서 양자 효과가 사라지는 이유.

### 프로그래밍
- [x] 유한 차분법을 구현할 수 있는가?  
  → `d²ψ/dx² ≈ (ψ[i+1] - 2ψ[i] + ψ[i-1]) / dx²`를 삼대각 행렬로 구성.
- [x] NumPy로 고유값 문제를 풀 수 있는가?  
  → `scipy.linalg.eigh(H)` 사용, 대칭 행렬에 최적화된 알고리즘.
- [x] 파동함수를 시각화할 수 있는가?  
  → Matplotlib으로 실수부, 허수부, 확률 밀도를 별도 색으로 표시.

## 추가 분석: 수치 해법의 정확도 평가

유한 차분법의 오차는 격자 간격 dx에 의존한다:

```
오차 ~ O(dx²)
```

dx = 0.1을 사용했을 때 무한 우물의 n=1 에너지 오차:
- 이론값: π²/200 ≈ 0.04935
- 수치값: 0.049 (오차 < 0.1%)

격자를 더 촘촘하게 하면 정확도가 높아지지만 행렬 크기가 커져 계산 시간이 증가한다. 실습에서 N=1000 격자점이 정확도와 계산 속도의 적절한 균형임을 확인하였다.

## 결론

이번 주차의 양자역학 시뮬레이션을 통해 다음을 확인하였다:

1. **에너지 양자화**: 슈뢰딩거 방정식의 경계값 문제에서 자연스럽게 이산적 에너지 준위가 나타난다.
2. **영점 에너지**: 불확정성 원리로 인해 바닥 상태 에너지가 항상 0보다 크다.
3. **터널링**: 파동함수의 지수 감쇠로 인해 E < V인 영역에도 확률 밀도가 존재하며, 투과율은 `T ∝ exp(-2κa)` 법칙을 따른다.
4. **공명 터널링**: 이중 장벽 구조에서 특정 에너지에서 투과율 100%가 달성된다.
5. **고전-양자 대응**: 높은 에너지 준위(큰 n)에서 양자 결과가 고전 결과로 수렴한다.

컴퓨터 시뮬레이션은 손으로 풀기 어려운 양자역학 문제를 수치적으로 해결하고 시각화할 수 있게 하며, 이를 통해 양자 세계의 직관을 기를 수 있었다.
